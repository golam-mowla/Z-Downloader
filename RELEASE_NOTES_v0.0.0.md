# ⚡ Z Downloader v0.0.0 Release Notes

**Z Downloader // Cyberpunk Edition** is a high-speed, lightweight media and BitTorrent downloader for Windows powered by Tauri 2, Rust, React 18, and TailwindCSS.

### 🌟 Key Highlights:
1. **Cyberpunk Aesthetic:** Deep dark obsidian backdrop with neon cyan, electric magenta, and neon yellow HUD styling.
2. **Circular Dragon Icon:** Custom ouroboros cyber dragon badge in multiple resolutions and Windows `.ico`.
3. **IDM-Style Browser Interception:** Chrome / Edge / Brave extension automatically detects and intercepts file downloads and sends them directly to Z Downloader.
4. **qBit Torrent Engine:** Built-in BitTorrent support for magnet links and `.torrent` files with DHT, peer metrics, and live transfer monitoring.
5. **Multi-Stream Acceleration:** 16 parallel connections powered by `aria2c` and `yt-dlp`.
6. **Windows Native Protocol:** Registered `zdownloader://` and `zdl://` URI scheme for seamless external integration.
7. **Ultra Lightweight:** Uses ~35-50 MB RAM with instantaneous launch.
